# Sales Data Analysis – Power BI Project

## About the Project
This project is done in Power BI. I took a sales dataset, cleaned it, added two new columns, and then created a dashboard to find useful insights from the data.

## Files
- `Task-1-PowerBI.pbix` – the Power BI project file
- `README.md` – project details

## What I Did
1. Cleaned the raw sales data (removed errors, fixed formatting, checked for invalid entries).
2. Added two new columns to the data for extra analysis.
3. Created measures (calculations) to find key insights.
4. Built a dashboard to show the results.

## Insights Found
- Total sales overall
- Total sales in Karachi
- Percentage of total sales coming from Karachi
- Total transactions in Karachi
- Total sales made through online and credit card payments
- Total sales excluding cash payments
- Number of transactions with unit price above 5000
- Total discount given on orders with quantity above 6
- Number of transactions from retail and distributor channels
- Check for valid/clean customer names

## Tools Used
- Power BI Desktop
- Power Query (for cleaning data)

## How to Open
1. Download the `.pbix` file from this repo.
2. Open it in Power BI Desktop.
3. View the dashboard and data.
